# Pi harness

**Verified:** 2026-11-16 against the official Pi documentation at github.com/earendil-works/pi (`packages/coding-agent/docs`, current as of release v1.5.2, 2026-11-10) and the pi.dev quickstart material
**Status:** Reference documentation, not a runtime conformance audit
**Primary scope:** `pi` CLI (npm `@earendil-works/pi-coding-agent` v1.5.2; interactive TUI, print mode, JSON event mode, RPC mode) plus the TypeScript SDK, `~/.pi/agent` configuration (`settings.json`, `models.json`, `auth.json`, `mcp.json`, `keybindings.json`), project `.pi/` directories with trust gating, tools and the tool pipeline, sessions as JSONL trees, extensions in TypeScript, skills/prompt templates/themes/packages, MCP (stdio + streamable HTTP, exposure model), codemode, no-approval security posture
**Provenance:** Official Pi sources (the repo's own docs) unless explicitly marked otherwise

Pi (Earendil Works; repo `earendil-works/pi`, formerly developed under the `badlogic` organization — the docs still link the `badlogic/pi-skills` collection) is "a minimal, extensible agent harness that you can make your own" — an open-source terminal coding agent that deliberately "ships with powerful defaults but skips features like sub-agents and plan mode." Sessions are persisted as JSONL trees: "Each tree entry has an ID and refers to its parent. The current entry identifies the active branch," so `/tree`, `/fork`, and `/clone` branch without erasing history, and compaction inserts a summary entry while "the original entries remain in the session tree." The security posture is explicit: "It does not ask before every tool call" — there is no approval-mode system; control comes from tool selection (`--tools`, `defaultTools`), project trust (which "controls whether Pi loads most settings and resources supplied by a working folder" but "does not limit what tool calls can access or affect"), extension permission gates on the `tool_call` event, and external isolation (Docker, Docker Sandboxes, OpenShell, or the Gondolin micro-VM extension). Extensions are TypeScript modules loaded into the Pi process via jiti and can register tools, commands, shortcuts, flags, providers, virtual models, and MCP servers. Machine surfaces are print mode, the JSON event stream, long-lived RPC mode, and the in-process TypeScript SDK — **there is no ACP support documented** (the only Zed reference is terminal keybindings for Zed's integrated terminal).

## Top corrections

- ❌ **“Pi asks before running commands.”** “It does not ask before every tool call.” The usage page adds: “Review commands and changed files, and use a sandbox for untrusted or unattended work.” There is no approval-mode system.
- ❌ **“Project trust sandboxes the agent.”** “Project trust does not limit what tool calls can access or affect. After Pi starts, enabled tools still use the operating-system permissions of the Pi process.”
- ❌ **“Pi includes sub-agents and plan mode.”** “Pi ships with powerful defaults but skips features like sub-agents and plan mode. Ask Pi to build what you want, or install a package that does it your way.”
- ❌ **“Pi supports ACP clients such as Zed.”** No ACP surface exists in the documentation; the machine surfaces are print mode, JSON mode, RPC mode, and the TypeScript SDK. The only Zed reference is “Zed integrated terminal” keybindings.
- ❌ **“Tool allowlists remove MCP tools.”** “`--tools` does not remove MCP tools unless one of its entries starts with `mcp__`” — reach is governed by each server's exposure (`codemode` by default, not even declared to the model).
- ❌ **“MCP servers can use the SSE transport.”** “`sse` is rejected. Servers that document an SSE endpoint often also provide streamable HTTP, commonly at `/mcp` instead of `/sse`.”
- ❌ **“Compaction deletes the original conversation.”** “Compaction adds a summary and keeps recent messages. It does not delete the original session entries,” and the session is a tree — “returning to an earlier point does not erase the branch you leave.”
- ❌ **“Environment variables are the first credential source.”** “Pi uses a runtime `--api-key` first, then a stored `auth.json` credential, an `apiKey` from `models.json`, and finally the provider's environment variables or ambient cloud credentials.”
- ❌ **“Codemode scripts can reach the filesystem and network.”** “The sandbox has no Node APIs, file system, network, or timers; scripts reach the outside world only through tools and `models`” — and `codemode` is off unless enabled or an MCP server activates it.
- ❌ **“`pi update` upgrades every install.”** “`pi update` cannot update Pi when another package manager provides it, such as Nix. Update Pi with that package manager, for example `nix profile upgrade pi`.”
- ⚠️ **“Skills load into context at startup.”** Only “each skill's name, description, and path” enter the system prompt; “the model reads `SKILL.md` and follows its instructions” when the task matches — or when forced with `/skill:name`.
- ❌ **“Session context is one linear transcript.”** Sessions are trees: “Messages and events in a session form a tree. Each path through that tree is a branch. The branch ending at the current entry is the active branch.”
