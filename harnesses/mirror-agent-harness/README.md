# Mirror harness

**Verified:** 2026-11-15 against the official Mirror CLI documentation at developers.reflection.ai (Mintlify `.md` exports) plus the reflection-oss/mirror GitHub repository
**Status:** Reference documentation, not a runtime conformance audit
**Primary scope:** `mirror` CLI (PyPI package `reflection-mirror`, Apache-2.0, Rust agent core behind a Python prompt-toolkit TUI; TUI, `mirror exec` noninteractive, `mirror acp`), `~/.mirror` data directory and `config.json`, workspaces (worktree / fork / folder / sandbox), manual and auto tool approval, Reflection + multi-provider models (`Beam-1.0-501B-A23B` default), `AGENTS.md`/skills/memory, connections and MCP, extensions in Python
**Provenance:** Official Reflection sources unless explicitly marked otherwise

Mirror (Reflection) is the terminal coding agent that Reflection ships alongside its `Beam-1.0-501B-A23B` model: an open-source (Apache-2.0) CLI, installed with `uv tool install reflection-mirror`, whose agent core is native Rust and whose interface is a Python prompt-toolkit TUI. One session holds workspaces ("a directory with its own agent and its own conversation"), conversations, tools, and instructions; each workspace keeps its own model, reasoning effort, and approval mode. Worktree workspaces (`/worktree`) branch `mirror/<name>` from the remote's default branch under `~/.mirror/worktrees/`, `/fork` copies the current files and conversation into a new workspace, and `/sandbox` runs file and shell tools in a microVM. Approval is manual by default — Mirror pauses before shell commands (including read-only ones), file writes and edits, connected-service tools, and most extension tools, while built-in file reading and searching never need approval — and the docs are explicit that approval "isn't a sandbox." Configuration lives in `~/.mirror/` (`config.json`, `cli.db`, `state.db`, `models.json`, `keybindings.json`), MCP server definitions are read only from `~/.mirror/mcp/` so cloning a repository can't add servers, extensions are Python classes loaded from `~/.mirror/extensions/` or a project's `.mirror/extensions/` with explicit consent, and there is no background execution: "Quitting Mirror stops every agent." Headless surfaces are `mirror exec` (one fresh session, no extensions) and `mirror acp` (Agent Client Protocol for clients such as Zed or Omnigent).

## Top corrections

- ❌ **“Mirror is Reflection's model.”** The model is `Beam-1.0-501B-A23B` (1M context, 128K max output); Mirror is the coding agent that uses it — “Mirror uses Reflection and `Beam-1.0-501B-A23B` unless you choose otherwise.”
- ❌ **“Mirror runs on Windows.”** “Mirror CLI runs on macOS 14 or later on Apple Silicon, and on Linux with glibc 2.28 or later on x86-64 or ARM64.” “Native Windows isn't supported.”
- ❌ **“Manual approval mode sandboxes the agent.”** “Approval mode decides what you review. It isn't a sandbox. Approved commands, extensions, and local MCP servers run with your account's full permissions.”
- ❌ **“Mirror asks before reading files.”** In manual mode only shell commands (“including ones that only read, such as `ls`”), file writes and edits, connected-service tools, and most extension tools pause; “Reading and searching files with the agent's built-in tools never needs approval.”
- ❌ **“Auto mode approves everything.”** In auto mode “Tools that require explicit confirmation still ask,” and “external extensions need consent before loading” regardless of approval mode.
- ❌ **“MCP servers can be configured per project.”** “Mirror only reads server definitions from this directory, never from a project, so cloning a repository can't add servers” — the directory is `~/.mirror/mcp/` (`MIRROR_MCP_DIR` to relocate). Project-level `.mirror/extensions/` do exist, but need consent.
- ❌ **“Mirror keeps working in the background.”** “Quitting Mirror stops every agent. Nothing keeps running in the background after you exit.” There is no scheduler or wakeup surface; remote gateways are “disabled unless configured.”
- ❌ **“`/rewind` restores files.”** “Rewinding changes only the conversation. Files the agent edited after that point stay as they are. Use version control to undo file changes.”
- ❌ **“`/drop` asks before deleting.”** “`/drop` deletes the checkout, including uncommitted changes, without asking first. Commit or copy anything you want to keep before you run it.” The `mirror/<name>` branch and saved conversations remain.
- ❌ **“`CLAUDE.md` takes precedence over `AGENTS.md`.”** “Mirror also reads `CLAUDE.md`, so a project that already has one works without changes. If a directory has both, Mirror uses `AGENTS.md`.”
- ❌ **“Reasoning effort starts low for speed.”** “Mirror starts at `max` unless the workspace has a saved effort or you pass `--reasoning-effort`”; `none` (“Provider default”) sends no effort setting at all.
- ❌ **“`mirror exec` resumes sessions and loads extensions.”** “`exec` starts a fresh session without extensions and doesn't support `--continue` or `--conversation-id`,” and it “rejects `--api-key`.”

## Quick reference

| Concern | Verified location or behavior |
|---|---|
| Install | `uv tool install reflection-mirror`; command is `mirror`; wheels bundle the native agent and ripgrep; macOS 14+ Apple Silicon, Linux glibc 2.28+ x86-64/ARM64, no native Windows; Git or Jujutsu needed only for worktree management |
| Entry points | `mirror` (TUI), `mirror 'prompt'` ≡ `mirror exec PROMPT` (one fresh local session, no TUI), `mirror acp` (Agent Client Protocol on stdin/stdout for Zed or Omnigent) |
| Data dir | Everything in `~/.mirror/`: `config.json`, `cli.db` (prompt history + workspace settings), `state.db` (conversations; `MIRROR_STATE_DB`), `models.json`, `keybindings.json`, `reflection_api_key`, `tool_approvals.json`, `skills/`, `extensions/`, `mcp/` (+ `credentials/`), `memory/`, `worktrees/`, `sandboxes/`, `logs/<conversation-id>/`, `analytics/` |
| Default model | `Beam-1.0-501B-A23B` (1,048,576-token context, 131,072 max output, reasoning mandatory, text input only); `--max-tokens` defaults to 64000 |
| Providers | `reflection`, `openrouter`, `openai-responses`, `anthropic-messages`, `gemini` (paid, `gemini-4-argon`), `openai-codex-responses` (ChatGPT plan via Codex sign-in), `openai-chat-completions` (+ `-non-streaming`); keys from `REFLECTION_API_KEY` etc.; exporting a key doesn't select the provider |
| Base URLs | `--base-url`; `OPENAI_BASE_URL`/`ANTHROPIC_BASE_URL`/`OPENROUTER_BASE_URL`; “If `OPENROUTER_BASE_URL` is set and you don't pass `--api`, Mirror uses Chat Completions with that endpoint instead of Reflection”; the `reflection` provider “doesn't accept another base URL” |
| Reasoning effort | `minimal`/`low`/`medium`/`high`/`xhigh`/`max` via `/effort` or `--reasoning-effort`; starts at `max`; `none` = provider default; per-workspace memory; Gemini allows only Provider default/low/medium/high |
| Approval | Manual (default) vs auto; F2 toggles, `/approvals` cycles, `--approval-mode auto\|approve` (default `approve`, saved); per-workspace in `~/.mirror/cli.db`; approval prompt: 1 approves, 2 rejects, Enter approves unless Reject is selected; Escape stops the whole turn |
| Workspace commands | `/worktree [name]`, `/fork [name]`, `/folder <path>`, `/sandbox [name]`, `/workspaces`, `/rename`, `/tag`, `/close`, `/drop` |
| Worktree mechanics | Branches `mirror/<name>` from the remote's default branch (`origin` preferred) under `~/.mirror/worktrees/`; fetch fallback to cached default branch or local committed revision; local edits and untracked files aren't copied; names up to 64 chars, must start with a letter or digit, no `..`, can't end in `.` or `.lock` |
| Switching | `Tab`/`Shift+Tab`, `Ctrl+1`…`Ctrl+9`, `Ctrl+O` or `/workspaces`; “Switching never stops an agent”; status ○ idle ● working `!` approval `✓` done `×` failed `·` not started `↻` saved conversation |
| Conversations | `/clear`, `/resume [id]` (Tab widens scope: directory → repository → all), `/rewind` (conversation branch only, files untouched), `--continue` per workspace, `--conversation-id <id>`; stored in `state.db` |
| Compaction | Summarizes near 90% of the context window; `--context-window`, `--compaction-threshold`, `--compaction-model`; `/compact` while idle; Escape cancels and a cancelled summary doesn't replace the context |
| Instructions | `~/.mirror/AGENTS.md` + every directory from repo root to the workspace dir; “Mirror reads at most 32 KiB of instructions in total and truncates the rest”; `CLAUDE.md` fallback |
| Skills | `~/.mirror/skills/<skill>/SKILL.md`, project `.agents/skills/` or `.claude/skills/` (root → working dir, six levels deep, nearest wins); `$` browses, `$<name>` mentions; `description` required, `name` defaults to directory, `disable-model-invocation: true` |
| Memory | Off until enabled in `/settings` → Memory; `~/.mirror/memory`, always-seen bullets in `~/.mirror/PINNED_MEMORIES.md`; `/memory import` imports Claude Code and Codex memories |
| MCP | Built-in connectors: Notion, Datadog, Linear, Slack (`/connect [service]`, browser sign-in, saved under `~/.mirror/mcp/credentials/`); custom servers as JSON in `~/.mirror/mcp/` only; `url` or `command`; `enabledTools`, `startupTimeoutSeconds` (15), `toolTimeoutSeconds` (300); tools named `mcp__<service>__<tool>` |
| Web search | You.com default (`YOU_API_KEY`), Tavily (`TAVILY_API_KEY`), Firecrawl (`FIRECRAWL_API_KEY`); selected with `/web-provider`; “Mirror doesn't fall back to another provider if a call fails” |
| Extensions | 18 bundled (`inference_controls`, `settings`, `connections`, `memory`, `context_usage`, `session_usage`, `web_provider`, `feedback`, `tokens_per_second`, `repository_status`, `editor`, `external_editor`, `themes`, `tips`, plus off-by-default `view_mode`, `vim`, `todo`, `user_extensions`); `/extensions` toggles; Python class subclassing `mirror.cli.extension.Extension`; tools named `<extension-id>__<tool>`; early beta |
| Headless | `mirror exec PROMPT` or `-` for stdin; requires prior interactive acceptance of the folder notices; rejects `--api-key`; approval-requiring calls fail unless `--approval-mode auto`; fresh session, no extensions, no `--continue`/`--conversation-id` |
| ACP | `mirror acp` serves Agent Client Protocol on stdin/stdout; approvals go to the client; fresh sessions without extensions; notices must have been accepted interactively |
| Remote | `--remote-endpoint <endpoint>` or `MIRROR_REMOTE_ENDPOINT` configures an agent gateway — “Remote gateways are disabled unless configured”; `--remote-insecure` allows plaintext gRPC on loopback only |
| Updates | Interactive update checks with prompts; `MIRROR_SKIP_UPDATE=1` bypasses checks and cached releases; `mirror update`; `uv tool upgrade reflection-mirror` |
| Automation limits | No daemon, scheduler, or wakeup: “Quitting Mirror stops every agent. Nothing keeps running in the background after you exit” |
| Analytics | Statsig product events (install/session/conversation IDs, version, OS, arch, locale, timezone, terminal, command/tool names, prompt length); never prompts/responses, code/file contents, tool arguments/output; off in `/settings` or `"analytics": false` |
